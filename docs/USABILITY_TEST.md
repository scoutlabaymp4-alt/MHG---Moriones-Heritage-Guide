# Usability test kit (for Week 3)

Purpose: get real evidence for the manuscript (Methodology and Results) about whether people can *use* MHG. This test measures usability. It does **not** measure learning, and the manuscript must not claim learning gains from it.

## Who and how many
- 5 to 8 adult volunteers (18+), for example BSIT classmates from another group. Do not test minors without guardian and school permission.
- Mix: at least 2 people who know the Moryonan well and 2 who do not.
- Sit with each person for about 10 minutes. Use a laptop or desktop computer (the site is desktop-first); note the screen size and browser.

## Ethics (read this script aloud)
"This is a class project. We are testing the website, not you. Taking part is voluntary and you can stop at any time. We will not record your name. We only note what you did and your answers."
- Do not record names, photos or audio. Use codes P1, P2, P3...
- Do not ask for opinions about religion or personal beliefs.

## Tasks (do not help unless the person is stuck for more than 1 minute)
| # | Task | Success when | Time (s) | Errors | Notes |
|---|---|---|---|---|---|
| T1 | "Find out what happens on Good Friday in Boac and save one event to your plan." | An event is saved in My plan | | | |
| T2 | "Use the directory to find a heritage site in Boac and open its source." | A source link is opened | | | |
| T3 | "Find out what the mask is made of, then take the quiz and finish it." | Mask part opened and quiz finished | | | |
| T4 | "Switch the guide to Filipino and find the etiquette checklist." | Language switched and checklist reached | | | |
Record: success (yes / yes with help / no), time in seconds, number of wrong clicks, and any comment in the person's own words.

## SUS questionnaire (System Usability Scale)
After the tasks, ask the person to rate each statement from 1 (strongly disagree) to 5 (strongly agree).
1. I think that I would like to use this website frequently.
2. I found the website unnecessarily complex.
3. I thought the website was easy to use.
4. I think that I would need the support of a technical person to be able to use this website.
5. I found the various functions in this website were well integrated.
6. I thought there was too much inconsistency in this website.
7. I would imagine that most people would learn to use this website very quickly.
8. I found the website very cumbersome to use.
9. I felt very confident using the website.
10. I needed to learn a lot of things before I could get going with this website.

**Scoring (per person):** for odd items (1,3,5,7,9) subtract 1 from the answer; for even items (2,4,6,8,10) subtract the answer from 5. Add the 10 results and multiply by 2.5. This gives 0 to 100. Report the mean and the range, together with n. A mean around 68 is commonly cited as average; with so few people, treat the result as indicative only.

Two extra questions (free text): "What was confusing?" and "Is anything in the guide disrespectful or wrong?" Pass any cultural concern to the group leader the same day and to the reviewer.
